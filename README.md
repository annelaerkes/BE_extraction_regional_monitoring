Extraction of perch and eelpout contaminant data from other sources (regional) than the national monitoring program (NMO). Extraction to be used in research projects on Integration of Biological Effects and contaminants.

Folders:

- original data contains original downloaded datasets. However for SGU, the data is now downloaded in the script directly from the SGU api.
- modified data contains the datasets modified to match the fmcom structure

Files:

- contaminants_SGU_NRM_copy.csv contains a copy of the master table to link contaminant information between SGU download and the format found in the fmcom dataset using SGU contaminant codes as the link.
- PFAS_tissue_conversion.xlsx contains information for converting between muscle and liver tissues for specific PFAS substances as discussed in Soerensen et al. 2023 and Soerensen and Larsen 2026.
